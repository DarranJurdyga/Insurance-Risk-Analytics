Motor Insurance Risk Analytics



Analysis of a Spanish motor insurance portfolio covering 2022–2024, using R, PostgreSQL and Excel. The project investigates claim frequency, claim severity and the impact of extreme losses on portfolio risk.



Tools



R: Data cleaning, exploratory analysis, statistical modelling and Monte Carlo simulation



PostgreSQL: Data validation, portfolio aggregation and risk segmentation



Excel: Power Query, PivotTables, Power Pivot/DAX and an insurance dashboard



Methodology



Clean and validate 354,140 policy-year records.



Analyse portfolio experience by year, policy type, driver age and vehicle characteristics.



Fit Poisson and Negative Binomial claim frequency models.



Compare Gamma and Lognormal severity distributions.



Apply Extreme Value Theory using a Generalised Pareto Distribution.



Simulate aggregate portfolio losses and calculate Value at Risk (VaR) and Tail Value at Risk (TVaR).



Key findings



Negative Binomial regression improved the fit to overdispersed claim counts; a 2024 holdout test underpredicted claims by approximately 3.4%.



The Lognormal model fitted the overall positive-severity distribution better than Gamma, although it underestimated the most extreme observations.



Adding an EVT-based tail produced much higher simulated aggregate risk estimates, particularly at the 99.9% confidence level.



These risk estimates are exploratory rather than actuarially validated capital requirements.

Data and reproducibility



Source: Espinosa, P., Lledó, J. and Atance, D. (2026), A detailed dataset of motor insurance policies with coverage-specific financial information, Mendeley Data, Version 1. https://doi.org/10.17632/sw4jmdb2sm.1



The source dataset and large saved model objects are not included in this repository. Reproducing the analysis requires downloading the dataset, preparing the local PostgreSQL database and configuring the R file paths. Some later R scripts depend on fitted model objects generated by earlier scripts.



Limitations



The severity observations are policy-year average incurred losses per claim count, not individual claim transactions. Using them as proxies for individual claim severities limits the interpretation of the simulated aggregate losses. Extreme-tail estimates are also sensitive to threshold choice, parameter uncertainty and simulation size.
